
Таблицу создают командой Вставка Таблица, выбирая нужное число строк и столбцов. Либо превращают в таблицу уже готовый текст - для этого выделяют фрагмент и применяют Преобразовать в таблицу, задавая разделитель, например табуляцию или точку с запятой. Редактирование ведут с помощью мыши либо клавиш Tab и стрелок, строки и столбцы добавляют или убирают через контекстное меню. Для сортировки отмечают нужные ячейки и запускают команду Сортировка, указывая столбец и порядок - по возрастанию либо по убыванию. Вычисления выполняют прямо в ячейке: ставят курсор, открывают Макет Формула и вводят выражение, к примеру =SUM(ABOVE) для суммирования значений выше.

Приложение запускают как обычную программу либо через создание новой электронной таблицы. В верхней части экрана находится заголовок с именем файла, ниже расположены меню и панели с кнопками для частых операций. Центральная область состоит из ячеек - столбцы обозначены буквами, строки цифрами. Слева и сверху видны заголовки столбцов и строк, внизу размещена строка состояния с полезной информацией. Новый документ создают командой Файл Создать либо сочетанием Ctrl+N. Первое сохранение выполняют через Сохранить как, указывая папку и имя файла, последующие обновления через Сохранить.
