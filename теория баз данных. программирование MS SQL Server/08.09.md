   # Основные понятия теории баз данных

данные - это информация представленная в определенном виде (в хаотичном или у порядочном формате)

база данных - это совокупность данных организованных по определенным правилам, предусматривающая хранение, описание, манипулирование и удаление данных.

##### субд 
(система управления баз данных) - это целый комплекс программ позволяющий создавать базу данных и манипулировать данными.

Microsoft SQL Server (MS SQL Server)
MySQL
Oracle
PostgreSQL
MongoDB

##### SQL 
язык специализированный для работы с базами данных.
особенности SQL:
1. не является самостоятельным языком программирования.
2. имеет четкую структуру, близок к естественному английскому языку.
3. декларативный характер, при написании кода пользователь указывает что хочет получить а система сама определяет как выполнить задачу

список диалектов языка SQL
1. T-SQL (TransactSQL) - используется в Microsoft SQL Server
2. PL/SQL (Procedural Language/SQL) - используется в Oracle
3. SQL/RSM - используется в MySQL
4. PLpg/SQL - используется в PostgreSQL
5. Jet SQL - используется в Microsoft Access

# Технологии работ с бд
 
**централизованная архитектура** - когда находится все на одном пк

преимущества:
1. очень легко управлять, потому что все находится в одном месте 
2. максимальная безопасность, никто не украдет данные 

недостатки:
1. колоссальная нагрузка на компьютер 
2. если сломается компьютер, может потеряться вся информация 


![[Диаграмма без названия (2).jpg]]



**архитектура файл сервер** - участвуют персональные компьютеры и выделенный сервер, на котором будут храниться файлы. сервер не учувствует в обработке своих данных.

преимущества:
1. дешево и просто настроить
2. каждый использует свою мощность пк для вычислений

недостатки:
1. огромный трафик
2. когда 2 человека и более используют, конфликт


![[Диаграмма без названия (3).jpg]]



**трехуровневая архитектура** (архитектура клиент сервер) 
  
  преимущества:
  1. гибкость
  2. масштабируемость
  3. снижение требований к пк клиента 
  4. повышена отказоустойчивость

недостатки:
1. сложная разработка
2. задержка ответа по сети
3. большие затраты на обслуживание
