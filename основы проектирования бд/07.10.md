# Ограничение в SQL

1. NULL (может не быть) / NOT NULL (обязательно) - гарантирует что в атрибуте будет или не будет значения 
2. UNIQUE -  обеспечивает уникальность значений в атрибуте или группе атрибутов (имена фамилии могут повторяться, а название группы нет)
3. PRIMARY KEY - (первичный ключ) однозначно идентифицирует каждую строку в сущности 
4. FOREIGN KEY - (внешний ключ) он гарантирует что значение в одной сущности соответствуют другой сущности. создает связь между двумя сущностями
5. CHECK - служит для проверки значений по определенному условию (можно ограничить, цена может быть отрицательна? поступать в колледж можно в любом возрасте? ограничить год рождения, не могут поступить дети младше 15 лет. можно ограничить запись, мы ждем например только 3 буквы потом тире потом цифры) что бы человек случайно не ввел неправильно
6. DEFAULT - устанавливает значение по умолчанию (если мы не запишем, он запишет сам)
